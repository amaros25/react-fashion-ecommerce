# How It Works - Screenshot Instructions

## Screenshot Locations

Please add your annotated screenshots to the following directory:
`public/images/how-it-works/`

## Required Screenshots

You need to create **4 screenshots** with numbered annotations:

### 1. Registration Page (`registration.png`)
**URL:** http://localhost:3000/register

**Annotations to add:**
- ① Role dropdown (Shopper/Seller selection)
- ② First Name and Last Name fields
- ③ Email field
- ④ Phone Number field
- ⑤ Profile Image upload area (for sellers)
- ⑥ Shop Name field (for sellers)
- ⑦ Register button

---

### 2. Login Page (`login.png`)
**URL:** http://localhost:3000/login

**Annotations to add:**
- ① Email or Phone Number field
- ② Password field
- ③ Forgot Password? link
- ④ Login button
- ⑤ Register link at bottom

---

### 3. Homepage (`homepage.png`)
**URL:** http://localhost:3000

**Annotations to add:**
- ① Language selector dropdown (EN/FR/AR)
- ② Navigation menu (Women's, Men's, Kids', Home)
- ③ Search bar
- ④ Header icons (Home, Profile, Saved, Cart)
- ⑤ Sort dropdown
- ⑥ A product card
- ⑦ Pagination controls

---

### 4. Product Page (`product-page.png`)
**URL:** http://localhost:3000/product/[any-product-id]

**Annotations to add:**
- ① Product image gallery
- ② Size selector
- ③ Color selector
- ④ Quantity selector
- ⑤ Add to Cart button
- ⑥ Buy Now button
- ⑦ Seller information section
- ⑧ Product description area

---

## How to Add Annotations

You can use any image editing tool (Photoshop, GIMP, Figma, etc.) to add:
- **White circular badges** with black numbers (①②③④⑤⑥⑦⑧)
- Position them near (but not covering) the UI elements
- Make sure they're clearly visible

## File Naming

Save the files with these exact names:
- `registration.png`
- `login.png`
- `homepage.png`
- `product-page.png`

## Notes

- The component is already built and ready to use
- Once you add the screenshots, the page will automatically display them
- The page supports all three languages (EN, FR, AR) with RTL support for Arabic
- All sections are collapsible except the introduction paragraph
- The design follows a minimalist Zara-style aesthetic
